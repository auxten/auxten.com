コテ kote

麺 noodles — the lazy op chain

キャベツ cabbage — one SQL plan

the whole chain compiles to a single query

生地 batter — the chDB engine

鉄板 teppan — your Python process

Hiroshima okonomiyaki is layered, never mixed — and so is this. Your pandas calls are the sauce on top; underneath, each call is recorded into a lazy chain, compiled into ONE SQL plan, and executed by the columnar engine only when you actually look at the result — len, print, iteration. That's why chained pandas ops stop costing a copy each: the layers cook as one. (Architecture diagram with the full detail: auxten.com slides repo.)

Ranged reads: you pay for the columns you touch — not the file.
Why "reading from S3 takes longer than the query" stops being true: the engine reads the Parquet footer first — schema plus statistics — then fetches only the column chunks the query touches, via HTTP Range requests. len() on 2.77M remote rows in 3.3 s without downloading. And streaming execution never materializes the full table: 344 MB peak versus pandas' 975 MB on the same file. Fair caveat for the notes: on very high-latency links, many small range requests can lose to one big download.

The abstract's second pain: you added embeddings and suddenly you're evaluating vector databases. MIGRATE · 移行19 / 21

Migrate like a daruma: one eye first

01

Swap at the I/O boundary. read_parquet / read_csv first — the cheapest, biggest wins.

02

Move the hot paths. The slow groupbys, the string filters — one column, one op at a time.

03

Mirror-test everything. Same input, both engines, assert equal — never trust, always verify.

04

Keep the escape hatch. .to_pandas() drops any result back — any op, any time.

Paint the second eye when the pipeline runs green.
Daruma: paint one eye when you set the goal, the second when you reach it. Migration the same way — not a rewrite, a sequence of one-line swaps. Start at the I/O boundary, chase hot paths, mirror-test each step (that's how I found the str.extract gap), and .to_pandas() means you're never trapped: any unsupported corner drops back to classic pandas mid-pipeline.
