How We Got Here

Four years of AI coding, compressed. It moved absurdly fast.

  • 2022 ChatGPT. Describe a function, copy the answer, paste into your editor.
  • 2024 Cursor + Claude Code. The AI moves inside the editor — reads your repo, runs your tests.
  • 2025 CLI agents & multi-agent pipelines. Codex and Claude Code in the terminal: test → fix → review → benchmark.
  • 2026 Autonomous, always-on agents. The question stops being "can it code?" and becomes "can it run without me, 24/7?"

From Copilot to Coworker

Same models underneath. Completely different relationship.

IDE Copilot

  • You drive, every keystroke
  • Lives in your editor session
  • Forgets everything when the tab closes
  • Stops the moment you close the laptop

Autonomous Agent

  • Lives on a server, runs 24/7
  • Persistent memory across sessions
  • Reaches you on chat — Discord, Telegram…
  • Learns its own skills, gets better over time

Think of it as hiring an ops teammate, not buying a faster autocomplete.

First, the Memory Trap

Build on my laptop (Cursor / Claude Code / Codex) → hand off to Hermes on the mini. Context evaporates.

The obvious fix: "just remember everything." That's the trap.

Auto-capture pollutes: a one-week vegetarian trip becomes my "permanent diet"; a Firebase idea I dropped months ago still haunts every design.

Bad memory is worse than no memory.

ClickMem — a memory safe

Remember what matters, forget what stopped being true, never treat a passing detail as your identity. A safe, not a firehose.

Expandadd a belief
Revisereplace when better info arrives
Contractforget — with a reason
Reinforcepin as authoritative
Refuseblacklist, never store again
  • Explicit-only. Two ways in: an agent commits a refined conclusion (clickmem_remember), or I import curated docs (AGENTS.md / CLAUDE.md / rules). Raw chat stays cold — never auto-injected.
  • Conflicts surfaced, not hidden. A new memory that contradicts an old one gets flagged for me to resolve — not silently stacked.

The One Rule

Treat your agent like a new hire. Give it its own email, its own user account, its own GitHub, its own machine.

Mine literally runs as a separate macOS user on the Mac mini. Blast-radius containment — if it does something destructive (and it will), it's in its own sandbox.

Also: use Time Machine.

Five Things I'd Tell You

  1. Infrastructure > prompts. — System engineering is the moat.
  2. One sentence can migrate your whole brain. — Portable skills + memory beat any lock-in.
  3. Bad memory is worse than no memory. — A real partner has to be able to forget.
  4. Reliability earns trust. — Instant ack + a closed loop beat raw capability.
  5. Treat it like a coworker, not a tool. — Containment = safety + freedom.
