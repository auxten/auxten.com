Fun fact #1

Killing the GIL: a 30-year graveyard

Guido's bar (2007): remove the GIL only if single-threaded performance does not decrease.
Gilectomy made every refcount atomic — and ran 19× slower on 7 cores than one.

Bonus fact: the 1996 patch left one survivor — PyThreadState is still in CPython today.

Fun fact #2

The black magic that makes it cheap

Biased refcounting

Two counters. The hot one never leaves its core.

Immortal objects

None's refcount is literally infinity — the hottest objects aren't counted at all.

Per-object locks

Mutations lock one object, not the world.

Lock-free reads

dict/list reads stay wait-free on the hot path.

Single-thread tax: ~40% in 3.13t → ~5–10% in 3.14t/3.15t — where Gilectomy cost 19×.
Fun fact #3

The GIL can come back — silently

✗One bad import poisons the well. Any un-opted-in C extension → CPython quietly turns the GIL back on for the whole process.
✗"Thread-safe because GIL" is now a data race. Every global, cache and lazy init loses its silent protection.
$ python3.14t -c "import _chdb"   # us, before we opted in
RuntimeWarning: The global interpreter lock (GIL) has been enabled to load
module '_chdb', which has not declared that it can run safely without the GIL.

This got us too: our own "no-GIL benchmark" spent a day measuring the GIL.

Ecosystem: ~61% of the top 360 compiled PyPI packages ship free-threaded wheels (Jul 2026) — but grpcio/protobuf don't, so much of the AI stack silently runs GIL-on. Trust nothing: check sys._is_gil_enabled().
Measured, not vibes

Real numbers from porting chDB

The win, isolated: a 5M-row object-dtype scan that must read one PyObject per value — exactly where the GIL used to serialize every thread.

stock 3.14 · 16 threads
0.22 s
3.14t · 16 threads
0.08 s

On stock 3.14, adding threads made it slower (0.13 → 0.22 s). On 3.14t the same threads make it 2.6× faster.

Honest part: the biggest win in the whole port was Arrow zero-copy (219 → 20 s), not no-GIL. Free-threading fixes what zero-copy can't reach — running actual Python in parallel.
