The idea03 / 14

Your agent's context is really a pile of data

"Context engineering" just means deciding what the agent sees each step. That's four kinds of data:

Instructions

Rules, constraints, preferences.

Working data

Files, tables, API results, logs.

Memory

Decisions, facts, prior solutions.

Eval history

What worked, what failed, what changed.

Recall = before each step, find the few facts that matter now. That's a query, not a bigger prompt.
Why a database04 / 14

"Can't I just use what I already have?"

SQLite

Great for tiny state. No columnar scan, no vector distance, no remote files.

pandas

Great in memory. Dies past RAM; can't query a remote file you never loaded.

DuckDB

Closest match — but thinner data-format support and no mature cloud.

Vector DB

Similarity only. Can't filter + join + aggregate + audit in one query.

Vector search is one operator. Agent memory is the whole data system around it.
ClickHouse05 / 14

ClickHouse in 60 seconds

If you've never met it (most of this room hasn't), here's all you need:

Analytical database

Open-source, for fast SQL over huge tables: logs, events, metrics, traces.

Columnar engine

Stores by column, so scans and aggregates over millions of rows stay fast.

More than storage

A real query engine: SQL, JSON, arrays, text search, vector distance.

OLAP, not OLTP: built to scan millions of rows, not fetch one. Runs Anthropic, Cursor, Cloudflare, Shopee.

Three sources, one query, no load step.

chdb.query("""
  SELECT u.name, u.age, o.total
  FROM url('https://api.co/users.parquet') u
  JOIN file('orders.csv')      o ON o.uid = u.uid
  JOIN Python(enriched_df)     e ON e.uid = u.uid
  WHERE u.age > 25
""")

Recall SQL10 / 14

Recall is one SQL query

Rank memories by meaning, keep the active ones, pinned first.

cosineDistance

how close two meanings are, as a number (0 = identical)

Need project, tags, or task-history? Add WHERE / JOIN lines — same query.

SELECT
  content,
  1 - cosineDistance(embedding, query_vec) AS meaning
FROM memories
WHERE status = 'active'
ORDER BY pinned DESC, meaning DESC
LIMIT 8
Local hot path11 / 14

Recall sits inside the agent loop

in-process recall

instant

remote recall in the loop

network tax

In the loop

Recall runs many times per turn — jitter becomes thinking-time jitter.

Retries hurt twice

A timed-out call is retried, and each retry re-sends the whole prompt.

Local wins

In-process recall is orders of magnitude faster, with no tail and no retries.
