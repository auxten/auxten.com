  LEFT JOIN file('local_orders.csv') orders
    ON users.uid = orders.uid

Before an agent trusts a file, it can compare it with the source of truth using the same SQL surface.

chdb.query("""
WITH local AS (
  SELECT count() rows,
         sum(amount) revenue,
         groupBitXor(cityHash64(*)) checksum
  FROM file('orders.parquet', Parquet)
),
cloud AS (
  SELECT count() rows,
         sum(amount) revenue,
         groupBitXor(cityHash64(*)) checksum
  FROM remoteSecure('cloud:9440', db, orders, ...)
)
SELECT
  local.rows = cloud.rows AS same_count,
  local.revenue = cloud.revenue AS same_revenue,
  local.checksum = cloud.checksum AS same_rows
FROM local, cloud
""")

sess.query("""
CREATE TABLE memories (
  id UUID,
  project_id LowCardinality(String),
  content String,
  tags Array(String),
  status Enum8('active' = 1, 'contracted' = 2),
  embedding Array(Float32),
  created_at DateTime64(3)
) ENGINE = MergeTree
ORDER BY (project_id, status, created_at)
""")

Recall SQL12 / 16

Recall is one SQL query

Structured filters + vector meaning + task history.

WHERE

project + status + tags + privacy

semantic recall against the query embedding

JOIN events

what solved a similar task before

chdb.query("""
SELECT
  m.id,
  m.content,
  1 - cosineDistance(m.embedding, {query_vec}) AS meaning,
  countIf(e.event = 'used_in_answer') AS used_before,
  max(e.created_at) AS last_used
FROM memories AS m
LEFT JOIN memory_events AS e ON e.memory_id = m.id
WHERE m.project_id = 'checkout-agent'
  AND m.status = 'active'
  AND hasAny(m.tags, ['sql', 'parquet', 'fidelity'])
GROUP BY m.id, m.content, m.embedding, m.pinned
ORDER BY m.pinned DESC, meaning DESC, used_before DESC
LIMIT 8
""")
