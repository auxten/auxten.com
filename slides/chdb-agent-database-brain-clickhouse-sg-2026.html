HONESTY

Where this stops

One writer per object. Great for a personal brain. A shared team memory belongs on a ClickHouse server.
Not OLTP. Frequent point updates and transactions belong in Postgres.
Durable V1 makes full checkpoints and does not clean up old ones. Keep one brain small.
Durable V1 does not encrypt. The lease coordinates writers; IAM is the security.
The gateway is yours to build. chDB gives you the object, not the router.
The browser demo is exact search. The HNSW index runs in native chDB.
