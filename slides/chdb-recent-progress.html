What is chDB?

An in-process SQL OLAP engine powered by ClickHouse — embedded directly in your Python process. No server. No setup.
  • Pandas-compatible DataStore API — familiar syntax, ClickHouse speed
  • 60+ formats — Parquet, CSV, JSON, Arrow, ORC…
  • 334 SQL functions — JOINs, CTEs, window, JSON
  • Zero-copy via Python memoryview
  • Python DB API 2.0 · 9 language bindings

DataStore: One-Line Pandas Swap


import chdb.datastore as pd  # <- one line!

df = pd.read_csv("employee_data.csv")
result = (
    df[(df['age'] > 25) & (df['salary'] > 50000)]
    .groupby('city')['salary']
    .agg(['mean', 'sum', 'count'])
    .sort_values('mean', ascending=False)
    .head(10)
)
